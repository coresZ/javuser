Jav Code Scanner 功能更新日志

只记「你又能做什么了」——版本号对应脚本设置里的版本
v1.5.762026-09-07
🧩 扩展系统来了：别人的油猴库，装进 JCS 用
新功能第三方油猴脚本一键接入 设置 → 扩展 → 粘贴脚本链接 → 添加
支持的库会出现在番号操作条上，变成一个专属按钮。添加时自动识别脚本名字，不用看天书链接。
新功能扩展管理台 设置 → 扩展
每个扩展一个开关（关掉立即生效，刷新后恢复）；不想要的点卸载；链接可一键复制；状态一眼看清（已注册 / 加载失败 / 仅注入）。
改进备份带上扩展配置 设置 → 备份 → 导出 / WebDAV 上传
换电脑或重装后，导入备份即可恢复全部扩展清单和开关状态，不用重新一个个加。
改进状态不再「误报失败」
以前某次网络抖动失败过，列表会一直显示「加载失败」；现在加载成功自动恢复「已注册」。
新功能官方扩展范例
Jable 老视频进度条实时预览已改造成 JCS 扩展——装上即用，这就是扩展能做到什么的示范。
v1.5.712026-08
📚 番号库 + 剧照预览需安装 Enhanced_Media_Helper
新功能一键收藏进番号库 番号旁 ⓘ 角标 / 操作条 ➕ 按钮
看到想留的番号点一下就进库；已入库的会亮角标，再点一下二次确认移除，防误触。
新功能AVWikiDB 剧照预览 操作条 📷 按钮（Shift + 点击 = 强制刷新）
直接调出该番号在 AVWikiDB 的整组剧照，灯箱翻页浏览。
新功能操作条自定义 设置 → 操作
字幕 / 复制 / 番号库 / 剧照四个按钮，每个都能单独「显示 / 隐藏 / 收进 ⋯ 菜单」。
v1.5.722026-08-30
🔓 打不开的站，现在也能搜了
改进403 / Cloudflare 拦截自动绕行
部分搜索源拒绝直接访问时，自动换三条路重试（直连补 cookie → 页面代取 → 代理），通常你完全无感；实在不行才提示用新标签打开。
改进剧照抓取同样自动绕行
AVWikiDB 剧照不再要求「先去网站转一圈种 cookie」，直接点就能出图。
v1.5.48–492026-08
👀 预览不再动不动弹新窗口
改进拒绝嵌入的源自动改用「直接渲染」
有的网站禁止被嵌进别人的页面。以前只能看提示；现在自动改用脚本直接渲染搜索结果，页内照样预览。
改进记忆你的选择
某个源确定打不开？记住它，下次直接新窗口不浪费时间；误判的可以在「设置 → 搜索源 → 黑名单」里移除恢复。
更早基础功能
每天都在用的那些
番号扫描高亮
打开页面自动识别番号并高亮成可点链接；支持自定义选择器（设置 → 高亮 → 框选，点一下页面元素就生成规则）。
多源搜索 + 页内预览
每个番号在 3+ 个搜索源间一键切换，预览窗口里直接看结果；每个源可选「自动 / 强制 iframe / 强制直接渲染」。
字幕搜索
操作条字幕按钮聚合多个字幕站，按番号直接搜。
WebDAV 全站备份可选加密
所有设置 + 各站点个性化配置上云，手机电脑同步一套配置。
深色 / 浅色主题 · 快捷键
Esc 逐层关闭 / 「/」快速搜索番号。
