A

源打不开怎么办？

自动降级：iframe 被拒 → 改用脚本直接渲染 → 再不行才提示新标签打开，并把该源记住。

记忆可在 设置→搜索源→黑名单 里撤销
B

每个源都能定制

设置 → 搜索源：加自己的源（支持 {code} 模板），并给每个源指定预览方式（自动 / 强制 iframe / 强制直接渲染）。

URL 模板示例：https://example.com/search?q={code}

05扩展系统：把别人的油猴库装进来

v1.5.73 起的新能力——任何按 JCS 扩展契约编写的脚本，都能变成番号操作条上的一个按钮。
1

添加

设置 → 扩展 → 粘贴脚本链接 → 添加。自动识别脚本名，不用记天书链接。

支持 http/https；本地服务也可以
2

使用

注册成功的扩展会出现在番号操作条上，和内置按钮一样点击使用。

状态看副行：已注册（绿）· 加载失败（红）
3

管理

每行开关立即生效（刷新恢复默认）；不用了点卸载；链接可一键复制分享。

备份会带上全部扩展清单

07疑难解答

现象原因与处理
扩展显示「加载失败」链接不可达（本地服务没开 / 404）。修复后刷新页面即自动清除失败标记
扩展能用但显示主机名而非名字该脚本未按扩展契约注册（自执行库），仍可运行但不受开关管控
番号库 / 剧照按钮不出现未安装 Enhanced_Media_Helper；剧照还需 EMH ≥ 3.6.4
某源总是弹新窗口该源已进黑名单（自动记忆）→ 设置 → 搜索源 → 黑名单 → 删除该域名
整站预览都弹新窗口本站被记为「禁止嵌入」→ 常规 tab 或 iframe 白名单里放行
换了电脑配置全没了备份 → WebDAV 上传过就登录拉取；否则导出 JSON 手动迁移（扩展清单也包含在内）
