# 18mh Dock 动作菜单（⋯）

日期：2026-09-22  
范围：`18mh/18mh.user.js` v4.4.0 → v4.5.0  
状态：已实现

## 目标

解决 Dock 图标按钮过多、无文字、移动端占满宽度的问题：把收藏/拉黑/阅读收进「⋯」气泡。

## Dock 结构

- 桌面 `[主按钮][书库][⋯][收起]`；收起逻辑与折叠球不变
- `⋯` 在本书已收藏或已拉黑时高亮（蓝底）+ 右上红点

## ⋯ 气泡

- 紧贴 `⋯` 下方 6px、右边缘对齐按钮；视口内做左右夹取
- 宽 78px（移动端 96px、行高 ≥40px 便于触控）
- 四项：**收藏 / 拉黑 / 阅读 / 分享**（图标 + 2 字）
  - 已收藏显示「已收藏」，已拉黑显示「已拉黑」，点击即取消
  - 阅读 = 在果核阅读器打开（`readerUrlById`，回退 `readerUrlByQuery`）
  - 分享 = `navigator.share`，不支持则复制链接并 toast
- 关闭时机：点击外部、Esc、滚动/尺寸变化、切换页面重建 Dock

## 图标

- `ICONS.more`（三点，fill）
- `ICONS.share`（Lucide share-2）

## 非目标

- 不改书库条目（已收藏/已下载）里的「阅读」按钮
- 不改主按钮/书库/收起行为
- 不改 WebDAV、状态、列表卡
